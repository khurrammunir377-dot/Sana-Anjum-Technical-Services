# Phase 7 UI & Operations Plan

Phase 7 completes the operational UI on top of Phases 1–6. Testing follows after Phase 7.

Screens: Dashboard, Leads/Customers, Quotations, Projects, Workers, Expenses, Invoices/Payments, Suppliers, Purchase Orders, Inventory, Stock Movements, Material Issue, Finance, VAT, Project Profitability, Settings.

Design principles: simple for 3 brothers + workers; fast data entry; AED; configurable 5% VAT; no customer portal; no enterprise HR; no complex accounting.

Phase 8/testing will test database migrations, API validation, calculations, permissions, document output, inventory movements, project costing, responsive UI and backup/restore.
