# SANA ANJUM TECHNICAL SERVICES

Dubai technical services, interior fit-out, AC/HVAC and maintenance management app.

## Two sides
- Public customer-facing website
- Internal business management system

No customer portal, enterprise HR, or full accounting ERP.

## Phase 1 + 2
Website, lead capture, customers, site visits, quotations, projects, tasks, regular/project workers, daily worker costs, expenses, invoices, payments, simple VAT fields, dashboard and project profitability foundation.

## Run locally
npm install
npm run dev

Public site: http://localhost:5173
Internal: http://localhost:5173/app
API: http://localhost:4000

Database: SQLite, created automatically in data/sats.db.

## Next phases
Extend this same codebase with suppliers, purchasing, inventory movements, subcontractors, deeper cash-flow/reporting and WhatsApp workflows.
